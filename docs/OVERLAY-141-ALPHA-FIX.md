# OVERLAY-141 · 圆角灰边根因与修法规格（主控 2026-09-06 夜，待额度恢复后实施）

## 0. 结论先行

**根因**：D2D 经 `ID2D1DCRenderTarget::BindDC` 输出到 DIB 时 **alpha 通道没有存活**，
随后 `apply_alpha_fixup`（`main.rs:2204`）的规则

```
a == 0 && (r|g|b) != 0  ⇒  提为完全不透明
```

把**抗锯齿产生的半透明边缘像素统统压成完全不透明** ——
1px 的柔和描边变成 2-3px 硬灰带，即 Gavin 报的「圆角包边灰色线条粗乱」。

**修法**：不再依赖 D2D 是否保真 alpha，改为**帧末按已知几何解析式写 alpha**。

## 1. 证据链（无需运行程序，症状本身即判据）

| 事实 | 出处 |
| --- | --- |
| 只有 `StreamingEditing` 走 SLWA，其余七态走 ULW | `main.rs:1343-1348` |
| 端测：录音 / 信息提示 / 错误**全坏**，编辑态**唯一正常** | Gavin 2026-09-06 端测 BUILD-135 |
| ⇒ 走 ULW 的全坏、没走的正常，**零反例** | 相关性钉死在 ULW 合成路径 |
| 半径不是变量：录音 r16、Error/Info r10，**坏法一样** | 排除「半径改动引入」 |
| 二值掩码已整体退役 | 排除「旧掩码残留」 |
| D2D 开了 `D2D1_ANTIALIAS_MODE_PER_PRIMITIVE` | `main.rs:3430` |
| 灰边本体是**有意设计**的 1px 描边 `OVERLAY_BORDER_GRAY = 0x3A3A3C` | `:1065`，D2D `DrawRoundedRectangle` `:3512` |

**决定性推理**：抗锯齿边缘像素**天生是部分 alpha**。
- 若 alpha 保真 ⇒ 边缘半透明 ⇒ **必然平滑**
- 若 alpha 丢失 ⇒ 被提亮规则压成全不透明 ⇒ **必然粗硬**

观察到的是后者 ⇒ **alpha 未保真**。症状即测量，不必再跑探针。

🔴 **coder-2 原方案的 worst-case 论证漏了这一处**：它只评估了「shimmer 渐变会变实」，
**没意识到圆角与描边的抗锯齿本身就是半透明渐变**，
所以把「几何仍正确、圆角外仍透明」当成了兜底成立的依据。

## 2. 修法规格（实施者照此执行）

### 2.1 用解析式圆角覆盖率直接写 alpha

替换 `apply_alpha_fixup` 的现有规则，帧末对每个像素：

```
sdf(x,y) = 圆角矩形有符号距离（标准 rounded-box SDF）
  qx = |x+0.5 - w/2| - (w/2 - r)
  qy = |y+0.5 - h/2| - (h/2 - r)
  d  = length(max(qx,0), max(qy,0)) + min(max(qx,qy), 0) - r
coverage = clamp(0.5 - d, 0.0, 1.0)        // 1px 解析抗锯齿
```

- `coverage == 0` ⇒ 四通道全零（真透明）
- 否则 `a = coverage · opacity · 255`，`rgb = 原色 · coverage · opacity`（预乘）

### 2.2 半径来源必须单一

各态窗口外框半径目前**散在各绘制函数里硬编码**
（录音 D2D `:3487` = 16.0；GDI 兜底 `draw_listening_placeholder:3073` = 10、
`draw_processing_overlay:4468` = 16 …）。

🔴 **实施时必须先把「窗口外框半径」收敛成单一来源**（状态 → 半径的映射函数），
绘制与掩码共用同一个值。**否则掩码与绘制半径不一致会切出新的锯齿。**
（注意甄别：`radiusX: 3.5/5.0/4.0` 等是麦克风图标、按钮等**内部元素**半径，不是窗口外框，不要一起改。）

### 2.3 顺带修掉的一个潜在缺陷

现规则里 `a == 0 && RGB == 0 ⇒ 保持透明`，意味着**形状内部的纯黑像素会变成透明洞**。
当前背景色是 `0x181818` 非纯黑所以没暴露，但纯黑文字/图标一旦出现就会穿孔。
解析掩码按几何给 alpha，**与像素颜色无关**，此缺陷一并消除。

### 2.4 代价（可接受，非回归）

窗口**内部**的真·逐像素半透明（如 shimmer 渐变）会退化为均一 alpha。
**但那正是 OVERLAY-121 之前的行为**，不算回归；
DEC-056 想要的视觉提升主要体现在圆角平滑，仍然达成。
