# 飞音智能语音输入 v0.9.0

**2026-09-10** ｜ Windows 10 / 11

自 `v0.5.4` 以来的第一个版本标记，包含 v0.6 ~ v0.9 的全部改动（341 次提交）。

---

## 亮点

- **边说边出字** —— 流式实时上屏，文字跟着语速平滑出现，录音中可直接点击修改
- **悬浮窗重制** —— 圆角、边框、半透明更细腻，麦克风图标带声波动画
- **输出更懂场景** —— 自动识别聊天 / 邮件 / 文档 / 终端 / AI 助手，给出不同语气与排版
- **说话再快也不丢字** —— 语速快、说得久、松开热键三类丢字问题集中修复
- **热键随心配** —— 左右修饰键可单独设置，任意组合键，含冲突检测

---

## v0.9.0（2026-08-30 ~ 09-10）

**新增**：麦克风声波动画 · 左 Alt / 左 Ctrl / 左 Shift 单键热键 · 托盘菜单图标 · 悬浮窗圆角与半透明优化

**修复**：语速快或说得久丢字 · 松手后句尾丢字 · 文字蹦字与中途卡顿 · 编辑框黑屏 / 右侧闪烁 / 大片空白 · 悬浮窗抖动、空窗、旧文字残留、圆角边框异常 · 热键首次录制无响应、右 Alt 误记成左 Ctrl、语音与翻译热键互相拦截 · 「一点点」「三五成群」等被误转数字 · 无序列举排不成列表 · 开翻译后场景规则失效 · 测试连接必定失败

**优化**：上屏字号调大 · 按真实语速显示 · 在线识别引擎升级 · 绘制引擎升级（休眠唤醒更稳） · 正式写作场景自动压缩口语冗余（聊天场景不动）

**变更**：移除自定义系统提示词入口（改为内置） · 在线识别选项精简为「本地 / 在线 FunASR」 · 972MB 大体积本地模型下线（旧配置自动迁回默认）

## 已知限制

- 浏览器场景无法细分网页内容类型，统一按正式写作处理
- 托盘图标偶发无响应（上游库已知问题），重启可恢复
- 悬浮窗绘制失败时自动回落兼容模式，视觉细节可能略有差异
