## 一、实验设计

提示词固定为当前 HEAD（阶段二 baseline），`temperature=0.3`，`<speech>` 包装。
以 IN-B（142 字）为基准，构造 7 组裁剪；IN-C 跑 2 组交叉验证。

| 编号 | 改动 | 想分离什么 |
|------|------|-----------|
| B0 | 原样（对照） | 必须复现 0/3 |
| B1 | 只删末尾总结句 | 总结句是不是充分条件 |
| B2 | 只删开头引入句 | 引入句有没有影响 |
| B3 | 引入句和总结句都删，只留三项 | 纯枚举能不能成 |
| B4 | 三个无序标记换成有序标记，其余全保留 | **最决定性**：同样的叙述框架下，有序能不能成？ |
| B5 | 只删口水词（啊/呃/呢），结构全保留 | 口水词有没有干扰判定 |
| B6 | 三项各缩短一半，引入+总结保留 | 长度是不是因素 |
| C0 | IN-C 原样 | 交叉验证 |
| C1' | IN-C 只删总结句 | 确认 B1 结论不是 IN-B 独有 |

## 三、一句话结论

**IN-B/IN-C 只要标记换成有序（第一/第二/第三），同样的叙述框架、同样的引入句+总结句、同样的长度、同样的口水词，就能 3/3 出列表。无序标记（比如/再比如/还有/还有就是）在引入句+总结句的框架下，即使删掉总结句、删掉引入句、甚至只剩纯三项，也始终出段落。**

→ **问题根因：当前提示词对「无序标记+框架句」的组合有系统性漏识别。** 有序标记因为有明确序列语义，能穿透框架句的干扰；无序标记（比如/再比如/还有）在框架句包围下，被 LLM 判定为「叙述中的举例修辞」而非「真正的枚举」。

---

## 四、推论与下一步

### 为什么 V8（混合结构授权）无效？

V8 加了一句「引入句+列表+收尾句是允许的」，但实验表明：
- 删掉总结句（B1）→ 仍不出列表
- 删掉引入句（B2）→ 仍不出列表  
- 两项都删只剩纯三项（B3）→ 仍不出列表

问题不是「允不允许混合结构」，而是 **LLM 根本没把这三项识别成枚举**。

### 真正该修的地方

F3 的「无序标记词表」需要加入**语义权重提示**，或者**增加框架句内枚举的 few-shot 示例**。当前的无序示例全是「纯枚举」形态（没有引入句+总结句），LLM 没见过「引入句+比如…再比如…+总结句」该出列表的例子。

建议增加一个专门针对「框架句内无序枚举」的 few-shot：

```
"今天的讲话指出了一些问题。比如说有些同学下课徘徊，再比如有的同学烫发，还有的同学不遵守纪律。上面的现象都不好。" → 
"- 有些同学下课徘徊\n- 有的同学烫发\n- 有的同学不遵守纪律"
```

（保留框架句为段落，只列表中间三项——这同时解决 V8 想解决的结构问题。）
