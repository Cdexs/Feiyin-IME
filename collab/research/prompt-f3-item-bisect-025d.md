## 三、关键发现：B9 推翻阶段三「框架彻底无关」假设

阶段三 B4（IN-B 框架 + 有序标记）3/3 ordered，似乎证明「框架无关，标记类型决定一切」。

但**B9（IN-A 项目 + IN-B 框架 + IN-A 无序标记）0/3 para** 证明：**同样的 IN-B 框架能把 IN-A 项目也压成段落**。

这说明框架**并非彻底无关**。

### 重新梳理所有证据

| 输入 | 引入句语义 | 项目内容 | 总结句 | 结果 |
|------|-----------|---------|--------|------|
| IN-A 原文 | "建议从以下方面入手"（枚举预设） | 动作建议，无内部标点 | 延续小句（非独立总结） | **3/3 bullet** |
| IN-B 原文 | "今天的讲话是要指出一些现象"（叙事预设） | 描述性长句，有内部标点 | 独立总结句 | **0/3 para** |
| B9 | "指出一些现象"（叙事预设） | IN-A 动作建议 | 独立总结句 | **0/3 para** |
| B1（阶段三） | "指出一些现象" | 描述性长句 | ❌ 已删 | **0/3 para** |
| B3（阶段三） | ❌ 无 | 描述性长句 | ❌ 无 | **0/3 para** |
| B10 | "指出一些现象" | 描述性长句去标点 | 独立总结句 | **0/3 para** |
| B8 | ❌ 无 | 描述性长句缩短 | ❌ 无 | **0/3 para** |
| B4（阶段三） | "指出一些现象" | 描述性长句 | 独立总结句 | **3/3 ordered**（但标记换成有序） |

### 新假设：「引入句语义预设」是决定性变量

**核心发现**：不是"有没有框架句"，而是**引入句的语义预设**。

- IN-A 引入句「建议从以下方面入手」**预设了"以下是多个方面的建议"** → LLM 看到"比如/再比如/还有"自然识别为枚举 → bullet
- IN-B 引入句「今天的讲话是要指出一些现象」**预设了"以下是一些现象的描述"** → LLM 把"比如/再比如/还有"理解为叙事中的举例修辞 → paragraph

这就解释了所有矛盾：
- B1 删总结句仍 para → 引入句的叙事预设没变
- B3 纯三项仍 para → 没有引入句预设，描述性内容本身不触发枚举
- B9 IN-A 项目放进 IN-B 框架仍 para → "指出现象"的叙事预设覆盖了项目内容
- B10 简化描述性长句仍 para → 叙事预设仍在
- B8 缩短无框架仍 para → 没有枚举预设，内容本身不触发
- **B4 换有序标记 3/3 ordered** → 有序标记自带"列表"语义，能穿透叙事预设

### 为什么 IN-A 原文成功而 B9 失败？

IN-A 原文引入句是「建议从以下方面入手」（枚举预设）+ 结尾是延续小句（非独立总结）。

B9 换成了 IN-B 的引入句「指出一些现象」（叙事预设）+ 独立总结句。

**两者共同把枚举预设替换成了叙事预设**，导致即使项目是 IN-A 的"动作建议"，也被判为叙事段落。

---

## 四、一句话结论

**决定成败的不是项目内容本身，也不是标记词类型本身，而是「引入句的语义预设」：当引入句预设了"列举建议/方案"时，无序标记能被识别为枚举；当引入句预设了"描述现象/叙述事件"时，同样的无序标记被识别为叙事中的举例修辞。** 独立总结句的存在进一步强化了这一叙事判定。

---

## 五、下一步建议

### 修法方向：增强无序标记的"枚举穿透力"

当前 F3 的语义并列判据依赖 LLM 对文本整体语义的判断。当引入句设定了叙事框架后，LLM 倾向于把所有内容都按叙事理解。

**建议**：在 F3 的 few-shot 示例中，**增加一个「叙事预设 + 无序枚举」的成功示例**，教会 LLM：即使文本整体是叙事，只要中间存在 2+ 个平行的具体项，仍应出列表。

示例：
```
"今天的讲话指出了学校的一些现象。比如说有些同学下课之后在校园里徘徊不走，三五成群；再比如有的同学烫发染发，不符合校规；还有的同学不遵守课堂纪律，顶撞老师。"
→ "- 有些同学下课之后在校园里徘徊不走，三五成群\n- 有的同学烫发染发，不符合校规\n- 有的同学不遵守课堂纪律，顶撞老师"
```

（这比 V8 的「混合结构授权」更有效——不是告诉 LLM "允许混合"，而是告诉它 "这种混合形态就该出列表"。）
