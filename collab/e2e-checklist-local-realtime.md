## 1. 切档入口（Ctrl+M 解锁，DEC-065）

- **步骤**：打开设置 →「语音」页；按一次 `Ctrl+M`；展开「ASR 模型」下拉。
- **预期**：
  - 下拉新增一项「本地流式实时模型」（en：`Local Streaming Realtime`）。
  - 设置窗口保持焦点下**再按一次 `Ctrl+M`，该项仍在**（**只开不关**，DEC-065；不得 toggle 消失）。
  - 关闭设置再打开，该项仍可见（`asr_local_realtime_unlocked=true` 已落盘，重启不丢）。
- **FAIL 判据**：选项不出现 / 再按 Ctrl+M 消失 / 重启后丢失。

## 2. 切档加载提示（Info 态，Gavin 指定短暂显示后自动关闭）

- **步骤**：选中「本地流式实时模型」；紧盯浮层；约 6 秒后尝试一次录音。
- **预期**：
  - 双模型（streaming paraformer 228MB + accuracy 972MB）加载期间，浮层出现 **Info 态**（**蓝点白字**）。
  - 提示**短暂显示后自动关闭**，不久留、不挡后续操作。
  - 模型未就位时按 `LOCAL-RT-FALLBACK-247` **直接报错**（浮层「所选模型不可用」），**不得静默降级**到其它档。
- **FAIL 判据**：无加载提示 / 提示久留不关 / 模型缺失时静默降级或崩。

## 3. 流式预览：逐字上屏、不得回退改写

- **步骤**：按住热键说一段较长中文（含数字/单位/专名），中途停顿后再继续。
- **预期**：
  - overlay 预览**逐字/逐词上屏**，文字随语速推进。
  - 已出现的文字**不得回退改写**（前缀单调；`235` PoC greedy 实测 0 改写 / 0 回退）。
  - 停顿处按 endpoint 切句，续说从新句开始。
- **FAIL 判据**：文字回退/被整段改写 / 长时间憋着不出字（中间结果频率异常）。

## 4. 松键后浮层单状态（DEC-066 附则一）+ 现有三档对照

- **步骤**：松键，紧盯浮层文案变化；**再分别用 performance / accuracy / 在线 fun_asr_realtime 各测一次**对照。
- **预期**：
  - **本地 realtime**：松键后浮层**只显示一次「识别处理中…」**，不得中途变字（不得跳到「转录中…」）。
  - **现有三档**：保持既有两段式行为不变（未被改坏）。
- **FAIL 判据**：本地 realtime 中途变字 / 现有三档任一出现行为变化。

## 5. 最终文本由 accuracy 产出（标点 + ITN + LLM）

- **步骤**：说一段含数字、单位、口语语气词的句子，检查注入结果。
- **预期**：最终注入文本由 **accuracy**（2pass offline）产出，**含标点**、**含 ITN**（数字/单位规整）、开 LLM 时**含去重/自我纠错**。预览文本（streaming greedy）与最终文本可不同，以最终注入为准。
- **FAIL 判据**：最终文本无标点 / 数字单位未规整 / 明显错字未纠。

## 6. 热词注入（accuracy 的 hotwords / LLM prompt）

- **步骤**：在词库加入专名（如「飞音」）；说含该专名的句子。
- **预期**：专名被正确识别（不被写成同音词）。
- **FAIL 判据**：专名被识别成同音错词且未纠正。

## 7. 编辑态：进入 → 修改 → 提交

- **步骤**：录音中点击 overlay 文本区进入编辑 → 修改文字 → `Enter` 提交；另测一次 `Esc` 取消。
- **预期**：编辑态可进入、光标可见、文字清晰无锯齿（EDIT 控件收到 `WM_SETFONT`）；提交后修改文本正确注入目标窗口；取消则丢弃、不注入。
- **FAIL 判据**：无法进入编辑 / 提交后注入未修改文本 / 取消仍注入。

## 8. 词库自学习（WORDBOOK-MINLEN-242 回归）

- **步骤**：编辑态提交两类改动：① 单字改动（一字替换另一字）；② 2 字及以上专名改动。分别在词库界面/日志核对。
- **预期**：① 单字改动**不得入库**（`MIN_CANDIDATE_CHARS=2`）；② 2 字及以上专名**应入库**。
- **FAIL 判据**：单字改动入库 / 2 字专名未入库。

## 9. 内存占用与释放

- **步骤**：切到 local_realtime 并完成一次录音；任务管理器观察 `voice-ime.exe` 内存；再切回 `performance`。
- **预期**：双模型常驻约 **1.6GB**（228MB streaming + 972MB accuracy + 运行时开销）；切回其它档后 streaming 模型**应释放**（内存回落）。
- **FAIL 判据**：切回后内存不降（模型泄漏）。

## 10. 🔴 现有三档零回归（最高约束）

- **步骤**：`performance` / `accuracy` / 在线 `fun_asr_realtime` 各完成一次「录音 → 注入」全流程。
- **预期**：行为与 **v0.9.2** 一致 —— 浮层两段式文案、注入内容与格式、热键、编辑态、词库学习均无变化。
- **FAIL 判据**：任一档出现任何行为差异 ⇒ **本批不通过**（Gavin 最高约束）。
