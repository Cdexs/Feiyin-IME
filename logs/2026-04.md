# 修改历史 · voice-ime · 2026-04

> 记录规则（Rule 7）：每次代码修改、优化或里程碑必须追加到本文件。
> 格式：`## YYYY-MM-DD — <一句话标题>`，正文说明改了什么、为什么、影响范围。

## 2026-04-14 — 恢复录音 overlay 胶囊样式与独立取消按钮

- 改动：`src/main.rs` 中的 Win32 overlay 绘制与点击处理，新增胶囊窗口 region、圆角背景/描边、左侧红点、独立取消按钮区域和按钮命中判断。
- 原因：修复 `BUG-007`、`BUG-008`，恢复录音悬浮条的原有视觉层次与取消交互，去掉“整窗单击即取消”的回归行为。
- 影响：录音态 overlay 的外观、波形布局和鼠标交互恢复为更接近原 `ui/overlay.rs` 的设计；FocusLost 复制行为保持不变。

## 2026-04-14 — 修复设置页优化模型探测误报失败

- 改动：`src/llm/mod.rs` 中的 `probe()` 改为三次重试，补充 `max_tokens: Some(5)` 与 `stream: Some(false)`，并新增连接超时、认证失败、4xx 请求错误的分类文案；`src/main.rs` 调整设置页失败提示为直接展示 probe 错误。
- 原因：修复 `BUG-009`，避免设置页“测试优化模型”因单次超时或瞬时连接抖动误判失败，同时减少部分 API 对 `max_tokens: null` 的兼容性问题。
- 影响：设置页 LLM 连通性测试对瞬时网络抖动更稳健；用户看到的失败提示更接近真实根因。

## 2026-04-14 — 修复 overlay 尺寸、处理中胶囊形与透明度配置接线

- 改动：`src/main.rs` 中录音/处理态 overlay 几何从 `620x84` 调整为 `480x52`，同步重排录音态红点、文本、波形和取消按钮布局；处理中状态改为圆角胶囊背景与蓝色文字；原生 Win32 overlay 增加 `opacity` 字段、`WS_EX_LAYERED` 和 `SetLayeredWindowAttributes`。
- 原因：修复取消按钮显示不全、处理中切换成方框，以及设置页透明度配置未真正作用到原生 overlay 的问题。
- 影响：录音与处理中 overlay 更紧凑，切换状态时保持胶囊形；设置页现有透明度滑条现在会影响下次弹出的原生 overlay。
