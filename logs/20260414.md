## 2026-04-14 — 补齐 Inno Setup 应用图标并完成安装脚本静态校验

## 2026-04-14 — 清理 overlay 历史 egui 死代码

- 改动：`src/ui/overlay.rs` 删除全部 `eframe/egui` overlay 绘制实现，仅保留 `AudioLevelBuf`、`OverlayStatus` 与音频电平缓冲辅助函数；移除 `OverlayStatus::Idle` 失活分支。
- 原因：录音/处理/预览 overlay 已完全由 `main.rs` 中的原生 Win32 窗口实现，旧 UI 绘制代码已无执行路径。
- 影响：`main.rs` 与 `audio/mod.rs` 继续复用 `ui::overlay::*` 共享状态；`cargo build` 通过，且无 overlay 相关 warning。

## 2026-04-14 — 修复 BUG-010 中文简繁输出不受控

- 改动：`Cargo.toml` 新增 `zhconv`；新增 `src/text_normalizer.rs` 统一封装 `chinese_script` 归一化；`src/transcription/mod.rs` 在 Whisper 输出后执行第一次转换；`src/main.rs` 在 LLM 成功与 fallback 汇总后再次执行转换，并把 LLM 额外指令从“仅繁体”补齐为“简体/繁体对称”。
- 原因：`zh` 语言码本身不区分简繁，原实现只在 UI 层保存 `chinese_script`，没有进入转录与最终输出链路，导致简体配置下仍可能输出繁体。
- 影响：中文脚本控制现在由 `chinese_script` 统一收口，覆盖 Whisper 原文、词库替换后文本、LLM 成功输出和 LLM 失败 fallback；相关单元测试与 `cargo build` 已通过。

## 2026-04-14 — 收紧录音态 overlay 尺寸并重排右侧取消按钮

- 改动：`src/main.rs` 将录音态 Win32 overlay 从 `480x52` 缩小到 `272x30`，保留处理态与焦点丢失预览的原尺寸；同步重排录音态内部布局，改为按窗口高度推导取消按钮宽度、右侧留白和波形区宽度。
- 原因：用户要求仅缩小波形窗口本身，同时保证右侧取消按钮完整显示，不被缩小后的布局挤压或裁切。
- 影响：录音态视觉更紧凑，取消按钮点击区仍稳定保留在最右侧；本次未改 `settings.rs`。构建验证被 `src/ui/settings.rs` 的现有类型错误阻塞，待 UI-005 修复后再做整仓编译确认。
