## 2026-09-21 — 主控根因分析：本地流式「中间句必丢尾字」（FIX-LOCALRT-TAILCHAR-291）

**输入**：Gavin 端测 BUILD-290 报两条 —— ① 首字仍不准 ② 长连续输入中**中间句**丢尾字。
**证据保全**：`target/release/debug.log`（406 行，02:00–02:20）即时 `cp` 进
`collab/evidence/20260921-gavin-e2e/debug-1018.log`，sha256 `b42c82341aff22b03717650ffbb7adaf4cae1dfb7a519288f3c13387adda3163`
（`[EVIDENCE-LOG-VOLATILE-001]`：该路径下次运行即被覆写）。

### 根因（结构性，非概率性）

`src/transcription/local_stream.rs::transcribe_streaming_local` 全函数只有**一处**
`stream.input_finished()`，位于 loop 之后（`:536`），只服务「录音结束时的最后一句」。
中间句的终止走 `if endpoint { recognizer.reset(&stream); … }`（`:415` 附近），
**reset 之前从未 flush** ⇒ sherpa 解码器里未吐出的最后一个 token 被 reset 丢弃。

⇒ **每一个被 endpoint 切掉的句子，结构上必然少最后一个字**；最后一句因有 flush 而完整。
与 Gavin 描述的「**中间的**句子」逐字吻合。

## 2026-09-21 — FIX-LOCALRT-TAILCHAR-291 · 本地流式「中间句必丢尾字」修复（coder-2）

**文件**：`src/transcription/local_stream.rs` **单文件**（改动随主控文档 commit `99799c5` 落盘；
同 commit 另含 `src/audio/mod.rs`=coder-1 292、`.gitignore`/docs，均非本单）。

**根因**：`transcribe_streaming_local` 里 `input_finished()` 全函数只在 loop 结束之后调用一次
（只救最后一句）；中间句走 `endpoint == true → recognizer.reset(&stream)`，**reset 前从未 flush**
⇒ sherpa 解码器里压着的最后一个 token 被直接丢弃，每一句被 endpoint 切掉的句子结构性少尾字。
最后一句因 loop 后的 flush 而完整 —— 正是 Gavin「**中间**句丢尾字」的原因。

**改动（方案 A）**：
1. endpoint 分支：`get_result`（flush 前，仅作回落）→ `stream.input_finished()` →
   `while is_ready { decode }` → `get_result`（flush 后，完整）→ 确认本句。
2. 新增私有纯函数 `endpoint_confirm_text(before, after)`：取字符更多者；flush 后空/更短则回落
   flush 前，**显式防整句消失 / 回退**（不靠运气）。
3. `input_finished()` 后 stream 不可复用 ⇒ 下一句改 `recognizer.create_stream()`
   （`let stream` → `let mut stream`），不再 `reset()`。
4. **不重复确认**：endpoint 分支确认一次，非 endpoint 分支保留原有 `on_result(..., false)` 一处
   ⇒ 不复发 FIX-252 标点/文本重复。
5. 埋点 `[LocalRT-DBG-291] endpoint flush: before_len/after_len/gained`，
   `debug!` + `log_enabled!(Debug)` 守卫（URGENT-286 零开销口径）。
6. 284/289 影子代码**未删**（修好后 `use_shadow` 预期恒假）；`RULE1/2/3`、`PRE_ROLL_MS`、
   `SHADOW_MAX_AUDIO_SECS`、269/269-B 标点触发一字未动。

**验证**：`cargo check --all-targets` 0 error、warnings **110/101** = 基线（早前一次读到 111/102
系 coder-1 `src/audio/mod.rs:248` 半成品态，非本单，已复归）；`rustfmt --edition 2021 --check`
clean；`cargo test --bin feiyin-ime local_stream::tests` **2P/0F**，连跑 3 次稳定。
