## PREROLL-RINGBUF-001 · 首字丢失根治

**根因分析**：
- `WarmInputStream.rx` 使用 `bounded(256)` + `try_send`
- 空闲 >2.56s 后 channel 满，热键触发瞬间 WASAPI 回调 `try_send` 失败
- 首段语音（约 4-10ms）被丢弃，ASR 缺失首字起音导致识别错误

**修复方案**：引入 `Arc<Mutex<VecDeque<Vec<f32>>>>` 环形缓冲区
- WASAPI 回调同时写环形缓冲区（自动淘汰最旧帧）+ try_send 到录音 channel
- `drain_pre_roll` 改为读环形缓冲区
- `record()` 开始时额外清空录音 channel

**改动内容**：

2. **`WarmInputStream` 结构体**：新增 `pre_roll: Arc<Mutex<VecDeque<Vec<f32>>>>` 字段

4. **三个 WASAPI 回调（F32/I16/U16）**：每个回调闭包外层 clone `pre_roll_cb` + `max_pr`，回调内先写环形缓冲区（`push_back` + `while total > max_pr { pop_front }`），再 `try_send` 到录音 channel
5. **`WarmInputStream` 初始化**：新增 `pre_roll` 字段赋值
6. **`drain_pre_roll`**：改为 `self.pre_roll.lock().unwrap().drain(..)` 读取环形缓冲区，不再 `self.rx.try_recv()`
7. **`record()`**：在 `drain_pre_roll` 后新增 `while warm.rx.try_recv().is_ok()` 清空录音 channel 中空闲期累积的静默帧
