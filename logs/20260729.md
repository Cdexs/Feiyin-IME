## 2026-07-29 — RESEARCH-DEEPSEEK-THINKING-001 验收：根因链修订为五环

coder-1 交付 504 行研究报告（4 个官方文档页 + 7 次脱敏 API 实测），主控独立核验通过，**推翻主控初判一处、主控回补其推测错误一处**。

**推翻**：主控原判「模型把思维链写进 `content`」不成立。DeepSeek 的 CoT 走独立字段 `reasoning_content`（官方 schema + 实测双证）。真实链路是 `max_tokens=512` 被 CoT 吃光 → `content=""` → **我们自己的 `extract_text`（`src/llm/mod.rs:962-993`）错误回落到 `reasoning_content`**，把 CoT 当答案。这是我方代码缺陷，不是模型行为。

**回补**：报告 Q3 推测 CoT「很可能被 `flatten_multiline` 或 `strip_fabricated_*` 压成 `...`」不成立。主控用日志定论——13:19 有 `suggestions after_tag` 日志（`debug.log:4416`），而该日志只在 `extract_corrected_tag` 返回 `Some` 的分支打印（`mod.rs:1005-1007`），故第 4 环是**首对标签提取抓到 CoT 里的模板占位**，与后处理层无关。12:06 无该日志行 → 走无标签兜底分支 → 护栏拦下，两次差异由此定论。

**其他确证**：`enable_thinking` 注入点实为 **4 处**（主控任务书漏了 `src-tauri/src/llm.rs:86`）；DeepSeek 对未知字段静默忽略，故该参数「发了一年多、不报错、不生效」；官方开关为 `thinking:{"type":"disabled"}`。

**产出**：`collab/research/deepseek-thinking-control-001.md`；`troubleshooting.md [LLM-COT-LEAK-001]` 已按定论版本修订；`todo.md` FIX-COT-LEAK-001-P0 由三项扩为五项，待 Gavin 拍板派发。API key 零泄漏（主控取真实 key 反向 grep 全部产出文件，零命中）。

## 2026-07-29 — RESEARCH-MACOS-DUALPLATFORM-001 验收：结论 GO（有条件），主控推翻其 CI 成本前提

coder-2 交付 370 行评估报告，主控独立核验通过，**三处修正**。

**修正一（最重要）**：报告 §3.4 的 CI 成本分析全篇按**私有仓库**计费（macOS $0.062/分钟、约 Linux 10.3 倍、2000 分钟/月按倍率折算），并据此设计了「若成本不可接受的退而求其次方案」。但主控实测 `api.github.com/repos/Cdexs/Feiyin-IME` → `"private": false` / `"visibility": "public"`，**本仓库是公开仓库**，标准 GitHub-hosted runner（含 macOS）对公开仓库**免费且不限量**（✅官方 billing 文档 + 2026 定价变更说明）。**结论反转**：成本不构成约束，该节不适用，可直接 push + PR 双触发甚至跑完整 `cargo test`；真实约束只剩单 job 6 小时上限与 cache 10GB 上限。

**修正二**：§4.2 称「`.gitignore` 未显式忽略根 `node_modules/`」有误——`.gitignore:12` 的裸 `node_modules` 模式在任意层级匹配，主控 `git check-ignore -v node_modules` 实证。

**修正三**：§1.3 用 `^\s*#\[test\]` 计得 631 并标 ⚠️ 质疑原报告的 633；主控 `grep -rn "#\[test\]" src/` 得 **633**，原报告无误。

**验证属实的部分**：§2 五项 P0 阻断、§7 六行签名漂移、`src/` 24504 行 / `main.rs` 4416 行、`accessibility.rs:43-48` stub、`.github/workflows/build-macos.yml` 存在（816 B）但被 `.gitignore:80` 排除从未进 git。

**两个核心判断经官方文档确认**：cargo `[env]` 不支持 per-target 且 `force=false` 时 shell 变量优先（Cargo Book）；`#[cfg]` 切掉的代码从 AST 移除不做类型检查（Rust Reference）→ **trait 不能防签名漂移，双平台 CI 是唯一可靠防线**。

**结论**：GO（有条件）。A 阶段最小 PR 约 140 行（仓库代码约 40 行 + 脚本/CI 新增），可在不触碰 Windows 运行行为下完成。前置条件：macOS 侧须先提交 setup/env 脚本、验证 sherpa-onnx osx-arm64 包与 ctranslate2 feature 组合、解除 `.gitignore` 的 `.github/` 排除。
