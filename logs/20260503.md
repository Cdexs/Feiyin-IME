### TASK-1: Transcriber 启动预初始化 + 持久化
- 文件：`src/main.rs` (spawn_worker_thread)
- 改动：将 `Transcriber::new()` 从每次录音时的 Start handler 内移到线程启动时，一次加载 ONNX 模型，所有录音会话复用。消除每次录音 1-2s 的模型加载延迟。
- 影响：首次录音启动速度提升 1-2s，后续录音零延迟。Transcriber 初始化失败时优雅降级（返回错误而非崩溃）。

### TASK-2: Hotkey 主循环改用 MsgWaitForMultipleObjects
- 文件：`src/platform/windows/hotkey.rs` (run_listener)
- 改动：替换 `PeekMessageW + sleep(10ms)` 为 `MsgWaitForMultipleObjects(Some(&[]), false, 10, QS_ALLINPUT)`。零 CPU 空闲等待，消息到达即时唤醒。
- 影响：热键响应延迟从最坏 10ms 降至 ~0ms，空闲 CPU 占用降至 0%。

### TASK-3: show_overlay 去 RwLock
- 文件：`src/main.rs` (show_overlay, process_controller_events)
- 改动：`show_overlay()` 函数签名从 `&Arc<RwLock<AppConfig>>` 改为直接接收 `overlay_opacity: f32, ui_language: UiLanguage`。调用方从已持有的 config 快照中提取这两个字段，避免不必要的 RwLock 读锁获取。
- 影响：减少 overlay 显示时的锁竞争，代码更清晰。

### TASK-4: 托盘菜单走 i18n
- 文件：`src/i18n.rs` (Strings struct, ZH, EN), `src/main.rs` (tray_menu_labels)
- 改动：新增 `tray_menu_settings` / `tray_menu_exit` 字段到 i18n Strings，`tray_menu_labels()` 从硬编码改为 `i18n::get()` 查找。修复中英文标签不一致问题（原中文为乱码）。
- 影响：托盘菜单标签与 tooltip 使用统一 i18n 路径，支持后续多语言扩展。

### TASK-5: 实心圆三态指示灯
- 文件：`src/main.rs` (draw_recording_overlay)
- 改动：新增 `RED_STREAM_FAILED` 常量 (#FF0000)，三态逻辑：
  - RED: audio buffer 为空（设备故障/流错误）
  - ORANGE: buffer 有数据且 level > 0.01（正常录音）
  - GRAY: buffer 有数据但 level <= 0.01（静音）
- 影响：用户可通过颜色直观判断设备状态，红色立即提示设备故障。
