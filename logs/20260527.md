## 2026-05-27 — coder-1 — FIRSTCHAR-FIX-005（降采样抗混叠根治）

- 范围：`src/audio/mod.rs`，根治 48kHz→16kHz 裸线性插值导致送气清声母（派/对/七）首字识别错误
- 方案：路径 A（整段抗混叠重采样），拒绝路径 C（sherpa 内置 LinearResample，回归面更大）
- 改动详述：
  1. 新增 `resample_anti_alias` 函数：Hann 窗 sinc 低通 + 多相 FIR，截止 ~7.2kHz（48→16kHz 3:1），TAPS=32
  2. `RecordingState::extend_samples` 改为 `extend_from_slice`（不再逐 chunk 重采样，存储原生采样率数据）
  3. `collect_recording` 末尾整段重采样：gain norm 后若 sample_rate≠16000 则调 `resample_anti_alias`
  4. `max_frames` 从硬编码 `16000*seconds` 改为 `sample_rate*seconds`（48kHz 下录音时长上限不再被截短 1/3）
  5. 录音完成日志除数从硬编码 `16000.0` 改为 `sample_rate as f32`
  6. `find_speech_anchor` 的 `WINDOW_SIZE=160` 改为 `sample_rate/100`（10ms 窗口随采样率缩放）
  7. 原 `resample_linear` 保留为 `#[cfg(test)]`（仅测试对照用）
  8. `all_samples` 预分配从 `16000*10` 改为 `sample_rate*10`
- 新增测试（7 个）：
  - `resample_anti_alias_preserves_low_frequency`：1kHz 正弦 48→16kHz 峰值保留
  - `resample_anti_alias_suppresses_high_frequency_aliasing`：500Hz+12kHz 复合，AA 峰值低于线性插值
  - `resample_anti_alias_identity_passthrough`：源=目标采样率原样复制
  - `resample_anti_alias_correct_output_length`：4800 样本 48→16kHz 产出 1600
  - `resample_anti_alias_attenuates_above_nyquist`：纯 12kHz 音经 AA 后 RMS<0.1
  - `find_speech_anchor_scales_with_sample_rate`：16kHz/48kHz 语音定位一致
  - `max_frames_uses_sample_rate_not_hardcoded`：48kHz×10s=480000
- 更新测试（1 个重命名 + 6 个参数更新）：
  - `recording_state_processes_pre_roll_with_same_vad_and_resampling_path` → `recording_state_stores_native_rate_samples`
  - `find_speech_anchor_*` 系列：新增 `sample_rate` 参数（16kHz 下行为不变）
- 不改动：D3 时间戳 drain / pre_roll 环形缓冲 / WASAPI 回调 / VAD 门限 / silence_duration 语义
- 验证：cargo check 0 errors / cargo test 全绿（237+16+3+12+10+2+9=289 passed / 0 failed / 2 ignored）
