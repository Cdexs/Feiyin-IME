## TRANS-REGRESSION-001 — 本地翻译两个回归 BUG 修复

### BUG-1：空格丢失
- **根因**：CT2 C FFI `result.output()` 返回 SentencePiece token（如 `["▁Hello", "▁World"]`），旧实现 `join(" ")` + `normalize_translation_output()` 的 `\u{2581}` 替换逻辑在处理 continuation piece 时不可靠，导致部分 token 组合下空格丢失。
- **修复**：`src/translation/mod.rs` `MarianModel::translate()` 改用已有的 `tokenizer.decode(&result_outputs)`（调用 `decode_pieces()`），由 SentencePiece 协议正确还原文本。
- **影响**：仅影响本地 CT2 翻译路径，LLM 翻译不受影响。

### BUG-2：翻译截断
- **根因**：`MAX_DECODE_STEPS=256` 对长录音（最长 180s）输入不足，中译英 token 数可达输入 1.5-2 倍。
- **修复**：`src/translation/mod.rs` `MAX_DECODE_STEPS` 256 → 512。
- **影响**：长语音翻译完整性改善，本地翻译路径仅有的改动。

### 测试
- `cargo test`：225 PASS / 0 FAIL / 4 IGNORED ✅
- 翻译专项测试全部通过，无回归。

## RESEARCH-CS-001 — SenseVoice 中英混合识别优化方案研究

### 核心发现
- SenseVoice 是 CTC 模型，**不支持 hotwords**（sherpa-onnx 官方文档已确认）
- Issue #3373 确认使用 hotwordsFile 会导致崩溃
- 当前模型为最新版（2025-09-09），暂无更新版本

### 研究结论（4 方案排序）

| 方案 | 优先级 | 难度 | 说明 |
|---|---|---|---|
| A. 参数调优 | 🥇 | 低 | language "auto"→"zh"，可选 blank_penalty，零成本 |
| B. Paraformer trilingual | 🥈 | 中 | 切换到 245MB 三语模型，原生 code-switching 训练 |
| C. LLM 后处理 | 🥉 | 低 | 提示词增强，修复英文拼写，无需改 ASR |
| D. Qwen3-ASR | 远期 | 高 | 600MB+ 体积过大，待模型成熟 |

### 影响
- 纯研究任务，无代码改动
- 建议立即实施方案 A，短期试点方案 C，中期评估方案 B
