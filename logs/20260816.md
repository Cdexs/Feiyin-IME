## 2026-08-16 — coder-1 · ASR-042 在线流式 ASR 采样率修复（StreamingResampler）

### 一、背景

Gavin v0.8.0 端测：新在线 ASR 识别结果全错（「你好，花呗还不上」等无关句子）。根因：麦克风 48000Hz 采集，服务端参数写死 `sample_rate: 16000`，中间零重采样。旧 `record()` 在录音结束时一次性 `resample_anti_alias`；`record_streaming` 边录边发没有那个时刻，步骤静默失效。

### 二、改动（仅 `src/audio/mod.rs`，+476/-5）

1. **新增 `StreamingResampler` 结构体**（`pub(crate)`）：带状态的流式抗混叠重采样器，数学等价于 `resample_anti_alias`（windowed-sinc FIR, TAPS=32, Hann 窗）。跨块保留历史样本 + 全局 `emitted` 计数，接缝处不截断卷积核。
   - `push(&[f32]) -> Vec<f32>`：喂一块，产出可安全输出的样本（右侧 lookahead 不足的留到下次）
   - `finish() -> Vec<f32>`：录音结束调，flush 尾部（与批处理版尾部截断一致）
   - 核心不变式：`src_pos = emitted / ratio` 用全局 emitted，绝不按块重置；drain 时只丢弃 `< next_lo` 的样本（精确，无 margin）
   - `source_rate == target_rate` 时 `push` 原样返回（与批处理版 `:900-902` 一致）
2. **`record_streaming` 接线**：pre-roll → post-hotkey → 主循环 依次喂进**同一个**实例；主循环 break 后调 `finish()`。新增日志 `Streaming resampler active: {N}Hz -> 16000Hz`。`total_samples`/`max_frames`/RMS/`level_buf` 继续用原始 chunk。
3. **新增 `RESAMPLE_TAPS` 常量**（`const`）：`resample_anti_alias` 的 `TAPS` 与 `StreamingResampler` 共用，防漂移。
4. **新增 6 条测试**：等价性（多频正弦+白噪声 1s，逐点差 ≤1e-5）、非对齐块长（441）、恒等（16k→16k）、长度（多种 n，误差 ≤1）、顺序护栏（pre-roll+post-hotkey+主循环 同一实例 vs 整段）、finish 尾部。

### 三、"改坏了会红"自证

在 `push` 入口注入 `self.emitted = 0`（模拟每块从 0 重算），跑 `streaming_resampler_equivalent_to_batch`：
- 结果：**FAILED**，`stream=807010` vs `batch=16000`（每块从 0 重算导致输出爆炸 50x）
- 移除注入后恢复 GREEN
