## 2026-07-30 — MACOS-PYTEST-COLLECT-FIX-001 完成（tester-1）

### 根因

两个独立问题阻塞 macOS 上 `pytest` 收集：

1. **缺少根 `pytest.ini`**：在仓库根目录直接 `pytest` 时无配置，CWD 全量递归 → 进入 `target/debug/.../googletest/` → `INTERNALERROR`
2. **两个 Windows-only 测试文件在模块导入级崩溃**：
   - `test_hotkey.py` → `ctypes.WinDLL("user32")`
   - `test_full_pipeline_e2e.py` → `import win32clipboard` → `ModuleNotFoundError`
   - 两者均 import `state_detector.py`（使用 `ctypes.wintypes` + `ctypes.windll.user32`）

### 三处改动

| 文件 | 改动 |
|------|------|
| `pytest.ini`（根） | `testpaths=tests` + `norecursedirs` 防护 + 合并 `tests/pytest.ini` 设置（addopts/markers/timeout） |
| `test_hotkey.py` | 模块级 `pytest.skip("Win32-only tests", allow_module_level=True)` 跳过非 Windows 平台 |
| `test_full_pipeline_e2e.py` | `import win32clipboard` → `win32clipboard = pytest.importorskip("win32clipboard")` |

### 约束落实

- `tests/pytest.ini` 未动（DEC-033/034）
- Windows 行为不变 —— 两个被跳过的文件原本就是 Windows-only；跳过干净利落不影响 Windows 收集/执行
- `state_detector.py` / `sendinput_hotkey.py` 在 macOS 上不再被导入
