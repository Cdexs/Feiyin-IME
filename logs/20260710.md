## 2026-07-10 — WORDBOOK-SINGLEWORD-001 前期研究结论（Orchestrator）

- 词库当前四个消费点：① `main.rs:2877` 转录后 `wb.apply()` 词对文本替换（所有模型生效）② `main.rs:2090` `load_hotwords_for_accuracy()` 取词对 corrected 侧构建 hotwords（仅 accuracy）③ `llm/mod.rs:456` `build_wordbook_prompt_block()` 以 XML 词对映射注入 LLM prompt ④ LLM suggestions（raw/corrected 词对）+ 频次阈值自动学习入库
- 关键事实：sherpa-onnx 1.12.38 中 hotwords 字段只存在于 `OfflineFunASRNanoModelConfig`（accuracy）与 `OfflineQwen3ASRModelConfig`；performance 使用的 `OfflineSenseVoiceModelConfig`（CTC）无 hotwords 接口，顶层 `hotwords_file` 仅适用 transducer+modified_beam_search 路径
- 结论：单词化词库对 performance 的生效通道只有 LLM prompt；方案已呈报 Gavin 待确认

## 2026-07-10 — ITN-SMART-001 智能数字规整模块

- **改动**：新增 `src/itn.rs` + `itn-rules.toml` + `src/main.rs` 挂载
- **核心能力**：
  - 中文数字→阿拉伯数字转换：进位组合（三百二十五→325）、小数点（三点一四→3.14）、逐位串≥2位（幺三八→138、九八→98）
  - 8 种语境引擎：时间（点后含进位单位或分/秒→时间非小数）、百分比、分数（X 分之 Y → Y/X）、序数、经纬度、负数（零下→-）、货币单位、通用量词
  - 保护机制：35+ 成语白名单、26+ 专有名词、13+ 虚词"一"搭配、15+ 通用量词前单字不转
  - 大金额保留万/亿（3500万元不展开）
  - 货币后小数模式（五块八→5块8）
- **架构**：算法与规则数据分离（`itn-rules.toml` 通过 `include_str!` 内置默认，运行时可覆盖）
- **管线位置**：转录后/LLM 前，三模型统一生效（`main.rs:2874`）
