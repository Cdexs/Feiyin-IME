## TRANS-CT2-DECODE-BUG-001 · CT2 双重解码修复

**文件**：`src/translation/mod.rs`
**改动**：第 355 行，删除二次 SentencePiece decode，直接使用 CT2 返回的已解码文本
**根因**：CT2 FFI `translation_result_output_at` 返回已解码文本字符串，被误当作 piece 序列二次解码导致英文空格丢失

```rust
// 旧：二次解码错误
let translated = self.tokenizer.decode(&result.output())?;

// 新：直接使用 CT2 已解码输出
let translated = result.output().first().cloned().unwrap_or_default();
```

**验证**：
- cargo test 133 PASS / 0 FAIL
- 翻译测试 8/8 PASS
- Release 构建成功，产物时间戳一致
