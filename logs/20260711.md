### 根因分析

migration 003 已将 `wordbook` 表从 `(raw, corrected)` 改为 `word` 单列并 DROP 旧表 RENAME 新表。但 `init_schema()` 每次打开数据库连接都无条件执行 MIGRATION_001（含 `CREATE UNIQUE INDEX IF NOT EXISTS idx_wordbook_unique ON wordbook(raw, corrected)`）。第二次启动时 `wordbook` 表只有 `word` 列，`CREATE TABLE IF NOT EXISTS` 是空操作，但 `CREATE UNIQUE INDEX` 因 `raw` 列不存在而报错 `no such column: raw`，此后所有词库操作永久失败。
